# Write-ups der Agent-Sessions

Hier legt jede Agent-Session (und jedes Teammitglied) ihr Write-up ab, damit eine Session daraus eine Gesamt-Zusammenfassung bauen kann.

Konvention:
- `docs/writeups/<person>_<thema>.md` – ein Write-up pro Arbeitsstrang (Ansatz, Daten, Ergebnisse mit Zahlen und Quelle, offene Punkte, Dateien/Befehle).
- Rohmaterial (Logs, JSON, Panel-/Recherche-Texte) in `docs/writeups/<person>_sources/`.
- Gemessenes von Annahmen trennen; Pfade relativ zum Repo-Root.
