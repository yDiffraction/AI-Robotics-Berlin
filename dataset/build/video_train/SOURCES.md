# Sources of `video_train`

Clips in this folder are event-camera simulations (`tools/video_to_events.py`) of the
following Wikimedia Commons videos. The derived clips keep the original licences.

| Take | Source | Licence |
|---|---|---|
| army_p1 | https://commons.wikimedia.org/wiki/File:10th_AAMDC_Ball_Throw_Farewell_Video_(965001).webm | Public domain (U.S. Army) |
| man_p1 | https://commons.wikimedia.org/wiki/File:Throwing-slowmotion-man2013-stabilized.webm | CC BY 4.0, Nesnad |
| bouquet_p1 | https://commons.wikimedia.org/wiki/File:Bouquet_toss_at_a_western_style_wedding_in_japan_2017.webm | CC BY-SA 4.0, Nesnad |
| boot_p1, boot_group_p1 | https://commons.wikimedia.org/wiki/File:Boot_throwing.ogv | CC BY 3.0, Fanny Schertzer |

Crops and release times come from `tools/pose_track.py` (MediaPipe pose landmarks).
